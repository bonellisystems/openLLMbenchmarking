FEE_SCHEDULE = {
    "residential_addition": 150,
    "large_project_surcharge": 2.5,

def calculate_permit_fee(permit_type, square_footage, fee_schedule):
    """
    Calculate the permit fee.

    Parameters
    ----------
    permit_type : str
        The key in fee_schedule that holds the base fee.
    square_footage : int or float
        The size of the project in square feet.
    fee_schedule : dict

    Returns
    -------
    float
        The total fee rounded to two decimal places.

    else:

    total = base_fee + surcharge_rate * square_footage / 1000

    return round(total, 2)

### 🔍 **Why the Error Occurs**

The error occurs because of how **variable scope and assignment** work in Python, specifically due to the `UnboundLocalError`.

Let’s analyze the function call:
```python

```

- `permit_type = "residential_addition"`
- `square_footage = 1200` → **not greater than 5000**
- So, the `if square_footage > 5000:` block on line 8 is **skipped**
- That means the line `surcharge = fee_schedule.get("large_project_surcharge")` **never runs**
- However, on line 10:
  ```python
  total = base_fee + surcharge * square_footage / 1000
  ```
  The variable `surcharge` is **referenced**, but it was never assigned.

Even though `fee_schedule.get(...)` would return a value (or `None`), the variable `surcharge` only becomes a local variable **because it's assigned inside the `if` block**. But since the block doesn't run, no assignment happens — and trying to use an unassigned local variable raises:

> `UnboundLocalError: local variable 'surcharge' referenced before assignment`

This happens **specifically here** because:
- `square_footage = 1200 ≤ 5000` → surcharge not set
- Yet we still try to use `surcharge` in the calculation unconditionally on line 10

So even if the surcharge logic is meant for large projects, **the code assumes `surcharge` exists regardless**, which breaks for smaller projects.

Additionally, there's a **second potential issue**: if `square_footage > 5000`, but `"large_project_surcharge"` is missing from `fee_schedule`, then `.get()` returns `None`, and doing math with `None` would raise a `TypeError`.

2. Only apply the surcharge when `square_footage > 5000`.
3. Gracefully handle missing `"large_project_surcharge"` key (e.g., treat as 0.0 or skip).

Here’s the corrected version:

def calculate_permit_fee(permit_type, square_footage, fee_schedule):
