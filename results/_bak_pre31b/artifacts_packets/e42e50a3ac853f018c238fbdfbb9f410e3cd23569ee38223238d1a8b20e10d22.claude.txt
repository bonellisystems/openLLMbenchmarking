### Explanation of the Error

The error occurs because of the conditional logic used to define the `surcharge` variable.

In Python, an `UnboundLocalError` is raised when you attempt to use a local variable in a calculation before it has been assigned a value. Here is the step-by-step execution for the call `calculate_permit_fee("residential_addition", 1200, FEE_SCHEDULE)`:

1.  **Line 7:** `base_fee` is assigned the value `150` from the dictionary.
2.  **Line 8:** The code checks if `square_footage > 5000`. Since `1200` is **not** greater than `5000`, the condition evaluates to `False`.
3.  **Line 9:** Because the `if` condition was `False`, the program **skips** the line `surcharge = fee_schedule.get(...)`. Consequently, the variable `surcharge` is never created in the local scope.
4.  **Line 10:** The program attempts to calculate `total = base_fee + surcharge * ...`. When Python tries to look up the value of `surcharge` to perform the multiplication, it finds that the variable has not been defined, triggering the `UnboundLocalError`.
