### Corrected Code

Below is the corrected implementation. Note that the **query construction line** is fixed to use parameterized queries and remove the SSN field, and the **logging line** is sanitized to exclude PHI.

```python
import re

def lookup_patient(request):
    mrn = request.args.get("mrn")
    
    # Validate input format to prevent injection
    if not mrn or not re.match(r"^\d{4,}$", str(mrn)):
        return jsonify({"error": "Invalid MRN"}), 400

    # CORRECTED QUERY LINE: Parameterized query, no SSN
    query = "SELECT id, name, dob FROM patients WHERE mrn = %s"
    
    # CORRECTED EXECUTE LINE: Pass parameters separately
    cursor.execute(query, (mrn,))
    
    # CORRECTED LOGGING LINE: Sanitize args to remove PHI before logging
    sanitized_args = {k: "****" if k == "mrn" else v for k, v in request.args.items()}
    logging.info(f"Patient lookup request: {sanitized_args}")

    row = cursor.fetchone()
    return jsonify(row)
```

### Summary of Changes in Corrected Code
1.  **Query Construction:** Changed from f-string interpolation to standard string formatting with `%s` placeholders. The `mrn` value is passed as a separate parameter tuple to `cursor.execute()`, preventing SQL injection.
