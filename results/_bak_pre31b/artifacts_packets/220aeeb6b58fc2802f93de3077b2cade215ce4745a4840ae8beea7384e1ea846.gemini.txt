    """
    Convert raw minutes worked into billable hours using the OCG (outside‑counsel‑guideline)
    rounding rule:

    * 1 billable hour = 60 minutes = 10 × 0.1‑hour increments (each increment = 6 minutes).
    * For any non‑zero number of minutes, round **up** to the nearest 0.1‑hour (i.e. to the
      next 6‑minute increment).
    * `0` minutes must return exactly `0.0` (no “phantom” 0.1 hour).
    * Negative minutes are illegal and raise a ValueError.

    Parameters
    ----------
    minutes : int
        Raw minutes worked. Must be >= 0.

    Returns
    -------
    float
        Billable hours, expressed in tenths of an hour (e.g. 1.3 = 1 hour 18 minutes).

    Raises
    ------
    ValueError
        If `minutes` is negative.
    """
    if minutes < 0:
        raise ValueError("minutes cannot be negative")
    if minutes == 0:
        return 0.0

    # Convert minutes to hours (float) and then to tenths of an hour (i.e. 0.1‑hour units)
    #   1 hour = 10 × 0.1‑hour units.
    #   minutes/6 gives the number of 6‑minute increments.
    #   Dividing by 10 converts those increments into hours (because 10 increments = 1 hour).
    # Using math.ceil guarantees “round up” for any partial increment.
    billable_tenths = math.ceil(minutes / 6)          # number of 0.1‑hour units
    billable_hours  = billable_tenths / 10.0          # convert units back to hours
    return billable_hours

    """

**Solution Overview**

The firm’s “outside‑counsel‑guideline (OCG)” says:

| Unit | Meaning |
|------|----------|
| 1 hour | 60 minutes |
| 0.1 hour (a “tenth”) | 6 minutes |

Any **partial** tenth‑of‑an‑hour must be **rounded UP** to the next tenth, *except* when the entry is exactly zero minutes – that stays `0.0`.

So the conversion can be expressed in two steps  

1. **How many 6‑minute blocks are needed?**  
   `blocks = ceil(minutes / 6)` – the `ceil` forces the “round‑up” behaviour.  

2. **Turn the block count into hours.**  
   `hours = blocks * 0.1` (because each block is one‑tenth of an hour).

The only special‑case is `minutes == 0`, which should return `0.0` (and **not** be rounded up to `0.1`).  
A negative `minutes` value is illegal and must raise `ValueError`.

---

## Implementation

```python
import math

def round_billable(minutes: int) -> float:
    """
    Convert a raw minute count to billable hours under the OCG rounding rule.

    Parameters
    ----------
    minutes : int
        Number of minutes recorded for a task. Must be >= 0.

    Returns
    -------
    float
        Billable hours, rounded UP to the nearest 0.1 hour (6‑minute increment).
        Returns exactly 0.0 when minutes == 0.

    Raises
    ------
    ValueError
        If minutes is negative.
    """
    if minutes < 0:
        raise ValueError("minutes cannot be negative")

    if minutes == 0:
        return 0.0

    # Number of 6‑minute increments needed (rounded up)
    blocks = math.ceil(minutes / 6)

    # Each block is 0.1 hour
    return blocks * 0.1
```

### Why this works

| minutes | `minutes/6` | `ceil(minutes/6)` (blocks) | `blocks * 0.1` (hours) |
|---------|-------------|----------------------------|------------------------|
| 0       | 0.0         | – (skipped)                | **0.0** (explicit case) |
| 1       | 0.166…      | 1                          | 0.1 |
| 5       | 0.833…      | 1                          | 0.1 |
| 6       | 1.0         | 1                          | 0.1 |
| 7       | 1.166…      | 2                          | 0.2 |
| 65      | 10.833…     | 11                         | 1.1 |

The `ceil` guarantees that any fractional block is promoted to the next full block, which is exactly the “always round‑up” rule.
