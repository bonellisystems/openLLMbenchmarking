```python
FEE_SCHEDULE = {
    "residential_addition": 150,
    "large_project_surcharge": 2.5,
}

def calculate_permit_fee(permit_type, square_footage, fee_schedule):
    """
    Calculate the permit fee based on the permit type and square footage.

    Args:
    - permit_type (str): The type of permit.
    - square_footage (int): The square footage of the project.
    - fee_schedule (dict): A dictionary containing the fee schedule.

    Returns:
    - float: The calculated permit fee.
    """
    base_fee = fee_schedule[permit_type]
    # Set surcharge to 0 by default
    surcharge = 0.0

    # Check if the fee schedule has a large project surcharge
    if "large_project_surcharge" in fee_schedule:
        large_project_surcharge = fee_schedule["large_project_surcharge"]
        if square_footage > 5000:
            surcharge = large_project_surcharge
    else:
        # Handle the case where the fee schedule is missing the large project surcharge
        if square_footage > 5000:
            raise ValueError("Fee schedule is missing the large project surcharge")

    total = base_fee + surcharge * square_footage / 1000
    return round(total, 2)

fee = calculate_permit_fee("residential_addition", 1200, FEE_SCHEDULE)
print(fee)
```

## Why Line 10 Fails

The `UnboundLocalError` occurs because `surcharge` is only defined inside the `if` block on **line 8–9**, and it is **never defined** when that block is skipped.

In the failing call:

- `square_footage = 1200`
- `1200 > 5000` → `False`
- So **line 9 never runs**, `surcharge` is never assigned
- **Line 10** then tries to evaluate `surcharge * 1200 / 1000`, which references an undefined local variable → `UnboundLocalError`

This same problem would also occur for any normal-sized permit (≤ 5000 sq ft), and silently fail to add the surcharge — which is incorrect behavior for large projects.

## Fixed Version

```python
FEE_SCHEDULE = {
    "residential_addition": 150,
    "large_project_surcharge": 2.5,
}

def calculate_permit_fee(permit_type, square_footage, fee_schedule):
    base_fee = fee_schedule[permit_type]
    if square_footage > 5000:
        surcharge = fee_schedule.get("large_project_surcharge", 0)
    else:
        surcharge = 0
    total = base_fee + surcharge * square_footage / 1000
    return round(total, 2)

fee = calculate_permit_fee("residential_addition", 1200, FEE_SCHEDULE)
print(fee)
```
