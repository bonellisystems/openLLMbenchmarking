## Task

Give the regex, classify all 7 strings against it, and explain specifically why using

### Why `re.search` breaks Test String 6

If you used `re.search(pattern, string)` (or `re.match` without anchors) on the string `TXN-0048291344-USDX` instead of `re.fullmatch`, the result would change from **NO MATCH** to **MATCH**.

Here is the specific mechanism behind this failure:

1.  **`re.search` is a substring scan:** It scans the string from left to right and returns `True` if the pattern is found *anywhere* within the string.
2.  **The "Hidden" Match:** In the string `TXN-0048291344-USDX`, the engine finds the valid sequence `TXN-0048291344-USD` starting at index 0. It successfully matches indices 0 through 18.
3.  **Ignored Tail:** Because `re.search` does not require the match to extend to the end of the string, it stops once it finds the valid substring and ignores the trailing `X`.
