### 3.  A clean refactor that *exactly* preserves the original semantics  

The original logic can be expressed as three mutually exclusive cases:

1. **Final punchlist **and** ≥ 100 % → `0.0`
2. **Not final punchlist** **and** `< 90 %` → `0.10`
3. **Everything else** → `0.05`

Putting those three cases together gives a compact, easily‑read function that never changes the result for any input combination.

```python
def get_retention_rate(percent_complete: float, is_final_punchlist: bool) -> float:
    """
    Return the retention rate according to the exact same rules as the original
    implementation.

    Cases (in order of precedence):
      1. Final punchlist AND percent_complete >= 100 → 0.0
      2. NOT final punchlist AND percent_complete < 90 → 0.10
      3. All remaining situations → 0.05
    """
    # 1️⃣ Final punchlist with >=100% completion → 0%
    if is_final_punchlist and percent_complete >= 100:
        return 0.0

    # 2️⃣ Not a final punchlist and still under 90% → 10%
    if not is_final_punchlist and percent_complete < 90:
        return 0.10

    # 3️⃣ Everything else → 5%
    return 0.05
```
