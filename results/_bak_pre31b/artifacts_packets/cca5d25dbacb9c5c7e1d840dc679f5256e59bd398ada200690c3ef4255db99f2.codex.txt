### Explanation of the Error

The `UnboundLocalError` occurs because of the **conditional scope** of the variable `surcharge`.

1.  **The Logic Flow:** In the call `calculate_permit_fee("residential_addition", 1200, FEE_SCHEDULE)`, the `square_footage` is `1200`.
2.  **The Condition:** The code reaches line 8: `if square_footage > 5000:`. Since `1200` is **not** greater than `5000`, the condition evaluates to `False`.
3.  **The Skip:** Because the condition is `False`, the code skips the entire indented block under the `if` statement (line 9). Consequently, the variable `surcharge` is **never created or assigned a value**.
4.  **The Crash:** The execution moves to line 10: `total = base_fee + surcharge * square_footage / 1000`. Python attempts to look up the value of `surcharge` to perform the math, but since that variable was never initialized in this function call, it throws the `UnboundLocalError`.

---

### Fixed Code

To fix this, we must ensure `surcharge` is defined even when the square footage is low. We also use the `.get()` method with a default value of `0` to satisfy the requirement of handling missing keys in the `fee_schedule`.

    "residential_addition": 150,
    "large_project_surcharge": 2.5,
}

def calculate_permit_fee(permit_type, square_footage, fee_schedule):
    # Use .get() for base_fee to avoid KeyError if permit_type is missing
    base_fee = fee_schedule.get(permit_type, 0)

    surcharge_rate = 0

    if square_footage > 5000:

## Fixed implementation

```python
FEE_SCHEDULE = {
    "residential_addition": 150,
    "large_project_surcharge": 2.5,   # optional – may be absent in some schedules
}


def calculate_permit_fee(permit_type, square_footage, fee_schedule):
    """
    Compute the permit fee for a given `permit_type`.

    * `base_fee` is looked up directly from the schedule.
    * If the project is larger than 5,000 sq ft, an additional
      `large_project_surcharge` (cents per sq ft) is applied.
    * Missing keys are handled gracefully:
        - unknown `permit_type` → raises a clear ValueError
        - missing `large_project_surcharge` → treated as 0
    * The result is rounded to two decimal places (cents).
    """
    # ------------------------------------------------------------------
    # 1️⃣  Validate that the requested permit_type exists
    # ------------------------------------------------------------------
    try:
        base_fee = fee_schedule[permit_type]
    except KeyError as exc:
        raise ValueError(
            f"Permit type '{permit_type}' is not defined in the fee schedule."
        ) from exc

    # ------------------------------------------------------------------
    # 2️⃣  Obtain the surcharge value, defaulting to 0 if the key is missing
    # ------------------------------------------------------------------
    # `.get` returns the value if present, otherwise the supplied default (0)
    large_project_rate = fee_schedule.get("large_project_surcharge", 0)

    # ------------------------------------------------------------------
    # 3️⃣  Compute the total fee
    # ------------------------------------------------------------------
    if square_footage > 5_000:                     # only apply surcharge when large
        # surcharge is expressed as a *percentage* (e.g., 2.5 means 2.5 % of the
        # square‑footage).  Multiplying by `square_footage / 1000` converts it
        # to a dollar amount that matches the original design.
        surcharge_amount = large_project_rate * square_footage / 1000
        total = base_fee + surcharge_amount
    else:
        # No surcharge for normal‑size projects
        total = base_fee

    # ------------------------------------------------------------------
    # 4️⃣  Return a nicely rounded monetary value
    # ------------------------------------------------------------------
    return round(total, 2)


# ----------------------------------------------------------------------
# Demo – the original failing case now works
# ----------------------------------------------------------------------
if __name__ == "__main__":
    fee = calculate_permit_fee("residential_addition", 1200, FEE_SCHEDULE)
    print(f"The permit fee is: ${fee}")          # → The permit fee is: $150.0
```

| Change | Reason |
|--------|--------|
| **`large_project_rate = fee_schedule.get("large_project_surcharge", 0)`** | Guarantees `large_project_rate` always has a value (0 when the key is absent). No `UnboundLocalError` can occur later. |
| **Move the surcharge calculation inside an `if square_footage > 5_000:` block** | The surcharge is only used when the project truly qualifies as “large”. For smaller projects the code never touches the `surcharge` variable. |
| **Separate `total` computation for the two cases** | Makes the logic explicit and prevents accidental use of an undefined variable. |
| **Added validation for missing `permit_type`** | Gives a clear error message instead of a generic `KeyError`. |
| **Used a constant `5_000` (instead of a magic number)** | Improves readability and makes the threshold easy to adjust. |
| **Rounded only at the very end** | Keeps intermediate calculations precise (important if the surcharge were a floating‑point percentage). |

    """

    Parameters

    permit_type : str
        The type of permit (must be a key in fee_schedule).
